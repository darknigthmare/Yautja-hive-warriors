Les frappes héritées utilisent maintenant la même autorité de scénario, époque et géométrie de toit que les appuis finis, sans nouvelle munition, coût ou capacité. Le helper refuse un contexte inconnu et vérifie le centre puis huit points de chaque empreinte via canAccessAir. Chaque cible effective est aussi vérifiée depuis sa position vers le ciel : une origine découverte ne permet pas de toucher un adversaire couvert.

OrbitalStrikeManager vérifie son disque avant le cooldown existant, puis filtre les vrais aliens et boss avant les dégâts. L’infiltration Player vérifie les six points d’impact avant le cooldown28, revalide chaque impact différé, filtre les cibles et retire les brûlures si le toit devient fermé. Les coûts et cooldowns existants restent inchangés ; une frappe retardée annulée ne rembourse pas son cooldown.

Six tests ciblés passent avec de vrais segments/colliders de toit et les méthodes des deux entrypoints : hangar, extérieur, point distant couvert, cible couverte distincte, contexte inconnu/époque, fermeture entre acceptation et impact, et brûlures après fermeture. La régression systèmes + ces six cas passe 29/29, zéro échec/omission/annulation. Le troisième entrypoint callPlanetaryOrbitalBarrage et le câblage du contexte dans main sont livrés et vérifiés séparément par l’agent d’intégration.

Ce contrôle est CPU uniquement. Aucun build, Git, navigateur ou action distante n’est exécuté pour ce lot. Il ne certifie ni fidélité1:1, ni performances matérielles, ni parties gagnées ou tests humains. Le commit et les hashes du prochain build final restent à fournir par root.
