# Lisibilité des petits plans et terrain lié à l’opération

Les quatre libellés AFF-27 contenaient chacun un paragraphe de plus de 100 caractères. Les dessiner intégralement sur les plans de 224 ou 360 pixels provoquait les chevauchements observés en novembre. Les données sources restent intactes. Les petits plans utilisent maintenant des repères stables `1…4`, et le briefing présente les descriptions complètes dans une liste qui se déroule et se fait défiler au clavier. La légende miniature affiche les titres des lieux ; les labels accessibles et les infobulles gardent le texte complet. Les mentions de contrôle inconnu restent visibles sous forme `?`.

Le panneau Musou conserve sa priorité de danger, mais affiche les mêmes repères et les titres des fronts au lieu de répéter leurs paragraphes dans sa ligne de priorité. Le rapport détaillé optionnel, les événements, les alertes et le débrief gardent leurs noms complets.

Le terrain sélectionné possède désormais un seul état visuel. Une assignation de `UIManager.selectedLevel` synchronise les cartes et leurs `aria-pressed`, y compris après reprise ou reconstruction de la grille. L’intégration appliquée par root dans `main.setupOperationSelection` appelle `setOperationLevel` dès le choix d’une opération. Lorsque celle-ci impose son terrain, les boutons de terrain sont désactivés et un texte explique comment retrouver un choix libre. Revenir à la chasse ou au pilote réactive immédiatement les cartes. Les assignations programmatiques de mission et de checkpoint demeurent possibles.

Les [24 tests ciblés](targeted-tests.txt) passent, dont neuf nouveaux cas dans `tests/operation-map-readability.test.js`. Ils contrôlent le clic contradictoire après AFF-27, le retour au choix libre, la reconstruction de grille, les identités des variantes, les labels inconnus, le véritable rendu des repères, les légendes et la présentation des priorités. La [première tentative](first-fixture-attempt.txt), à dix réussites sur douze, est conservée : deux échecs provenaient d’un objet `style` manquant dans la fixture DOM, corrigée sans adapter le runtime à ce défaut de test.

Le [rapport ciblé](validation.json) décrit un arbre en cours d’intégration. Aucun navigateur n’a été lancé par cet agent ; les captures à 800×600 et 1280×720, le défilement et le focus visibles doivent être évalués par la QA navigateur indépendante. Aucun critère global AUD-103/AUD-032, aucune performance matérielle, recette humaine ou fidélité visuelle 1:1 n’est clôturé par ces tests.
