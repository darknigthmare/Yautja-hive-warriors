The removed object owns its `InstancedMesh` instance buffers independently of its geometry and material. Three r160 releases them through the mesh dispose event. `disposeObject` now dispatches that event once per instance mesh while retaining explicitly borrowed geometry/materials and the lifetime-wide PBR texture cache.

The two meaningful lifecycle probes failed before the change and pass after it. They remove one actor while a peer retains shared surfaces, then remove the peer, and also check two independently owned instance meshes against one shared geometry/material. An ordinary Mesh custom dispose hook is not called. `SupportAssembly` was extracted without changing its body; its initial 18 support tests passed before model replacement.

Independent review caught an APC regression: the vehicle had two manual wheel-instance disposal calls which would duplicate the new central owner. Both calls were removed. The pre-existing convoy assertion again receives exactly one event. Review also found the gait hook ran before final world/APC/capsule collisions; the hook now runs after those contacts, with a real blocked APC regression in the final suite.
