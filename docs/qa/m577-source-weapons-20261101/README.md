# M577A — séparation des armes avant et arrière (novembre 2026)

Le *Colonial Marines Technical Manual* distingue la tourelle
avant RE700 de 20 mm et la tourelle arrière coulissante,
dont la variante M577A contient deux Boyars PARS 150 à plasma.
Jusqu'à présent le code qualifiait le double canon arrière
d'autocanon de 20 mm.

La tourelle arrière émet désormais un effet de jeu de type
`plasma` avec un traceur bleu-blanc **interprété** ; la
tourelle RE700 avant est déclarée **visuelle mais non jouable**.
Les paramètres de dégâts, cadence et stock `rounds` sont des
réglages Musou **non équivalents** aux spécifications du livre.
La clé de sauvegarde `rounds` est conservée pour ne pas
réinitialiser les munitions ni casser les checkpoints historiques.

Restent à faire : effet/son plasma source 1:1, deux armes avant
réellement séparées, systèmes A2 laser et A3 particules, modes
de feu, surchauffe/portée sourcées et véritable comparaison des
matériaux/maquettes du film.

Référence documentaire : https://www.avpcentral.com/aliens-colonial-marines-technical-manual
